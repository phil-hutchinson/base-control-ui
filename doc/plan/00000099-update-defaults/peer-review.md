# Peer Review — Update the start screen's default options

## Summary

The branch reselects the start screen's eight preselected options by moving
four constants — `DEFAULT_FLEET_SIZE` 6 → 5, `DEFAULT_CHARGED_NODE_COUNT`
5 → 4, `DEFAULT_SCORING` simple → bonus, `DEFAULT_NODE_ROTATION` continuous →
planet — and then follows the consequences through the comments that named
the old values, the 26 tests that asserted them, and the README prose that
states each preselection to a player. No rule logic changes, and `rules.md`,
`changelog.md` and `RULES_VERSION` are correctly absent from the diff, which
matches both the story and the ruleset's position that the document names no
default.

`npm run typecheck` passes, `npm run lint` passes, and `npm test` passes
(78 files, 1522 tests); `npm run format:check` also passes. The plan's two
steps are both recorded Done with accurate Notes, the constants really are the
single source of the preselection (only `useAppScreen.ts` and `gameState.ts`
read them), and the five-a-side layout the new default deals matches
`rules.md` §4 square for square. The implementation plan's Step 2 is a
README-up-to-date step, so that requirement is met. The findings below are
about leftovers the sweep missed — two test names still asserting the claim
the story set out to remove, and three rule-test harnesses that silently
changed which setting they exercise — plus two README sentences that the new
defaults make inaccurate.
