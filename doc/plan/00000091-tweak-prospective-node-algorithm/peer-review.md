# Peer Review — Story 00000091, Nodes reach the edge

## Summary

The branch moves the refill pool's widening one draw later and opens both edge
constraints together, so a refill's third square can land anywhere on the board
including a corner, while the opening deal draws all three inactive squares from
the strict pool and stays inside C3–M13. It lands as five commits: the 0.36 →
0.37 rules edit with one changelog entry and a matching `RULES_VERSION`; the
code change (`WIDENED_EXCLUDED_EDGE_RINGS` 1 → 0, `refillQueue`'s new
`thirdSquarePoolWidth` parameter, `dealOpeningBoard` passing `"strict"`) with
its tests; re-measured `tech-notes.md` figures; the owner's manual pass; and the
README clause plus the `story.md` correction. Checks from the repository root:
`npm run typecheck` **clean**, `npm run lint` **clean**, `npm test` **73 files,
1454 tests, all passing**. The rules document, `RULES_VERSION`, the changelog
entry and the code all agree, the 51 / 117 / 38 figures reproduce exactly, and
no tag was created; the findings below are one inverted measurement narrative
and a handful of comment-convention and documentation points.
