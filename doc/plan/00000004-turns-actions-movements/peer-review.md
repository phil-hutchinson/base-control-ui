# Peer Review — 00000004 Plies, actions and movement

## Summary

The branch implements §6 movement (reach table, straight lines, clear path,
board edges, the dormant/depleted landing ban), §3.1's bay reset and §5's
plies, actions and pass guard as pure modules in `src/rules/`, adds a
`src/game/session.ts` selection grammar, and turns the board from a
module-level constant into a picture of a game state that the player drives by
keyboard or mouse, with a turn indicator, three new square markings and a live
region. `doc/ruleset/` is untouched and `RULES_VERSION` stays `"0.3"`, as the
story requires; all twenty plan steps are marked committed and the Step 14
fixture is fully gone (`grep -r reviewFixture src` finds nothing, and no test
references it).

Verification from the repository root: `npm run typecheck` **passes**,
`npm run lint` **passes** (no findings), `npm test` **passes** (23 files, 248
tests). `npm run format:check` and `npm run build` also pass. The rule logic in
`src/rules/` was read against `doc/ruleset/rules.md` §3.1, §5, §6, §7.2 and
§8.5 and matches it; no rule the document does not state was found in the code.
The findings below are all wording, coverage, comment-convention and
design-duplication points, plus one story requirement (a visible reason for a
rejected input) that the shipped app does not meet.
