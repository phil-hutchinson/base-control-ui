## Summary

The branch replaces §8.4's escalating payout table (1, 3, 6, 10) with a flat
one energy per charged node held: `rules.md` §8.4 is rewritten and bumped to
0.29 with a matching `changelog.md` entry and `RULES_VERSION`,
`ENERGY_BY_NODES_HELD` and `energyForNodesHeld` are deleted outright,
`endOfTurn.ts` step 2 awards `heldSquares.length` behind the unchanged
`amount > 0` guard, the engine and hand-built display fixtures are renumbered,
and `README.md` states the flat rate. The diff matches the story and the plan
closely — the ruleset, the version constant and the changelog all moved
together, no production code outside `energy.ts` and `endOfTurn.ts` changed,
and every step's Notes line records what was done, including the two
documented deviations (Step 4's unchecked announcement point, Step 5's direct
README edit in place of `/update-readme`).

`npm run typecheck` passes. `npm run lint` passes with no findings.
`npm test` passes: 59 files, 1039 tests. (`npm run format:check` also passes.)
The plan does include a README step — Step 5 — so no comment is raised on that
count. Findings below are one stale rule figure left in the HUD by Step 5's
sweep, plus comment-convention and prose points; nothing blocks the story.
