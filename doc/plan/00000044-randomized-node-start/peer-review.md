# Peer Review — 00000044 A randomized opening board

## Summary

The branch replaces the fixed opening (H8, E5, K5, E11, K11 at drain 0, the
rest active at pressure 1) with a seeded deal: `dealOpeningBoard(seed)` in
`src/rules/sites.ts` draws five of the seventeen sites uniformly without
replacement, then walks `SITES` once drawing each site's opening drain or
opening pressure from two new `WeightedAmount` tables, consuming exactly 22
seed steps; `startingGameState` calls it and stores the advanced seed.
`rules.md` moves 0.17 → 0.18 with a changelog entry and a matching
`RULES_VERSION`, the tests that leaned on the fixed opening now state the
board they want, and new cover lands in `sites.test.ts`,
`gameState.test.ts`, `openingBoard.test.ts` and `seededReplay.test.ts`.

Verification run from the repository root: **`npm run typecheck` passes**,
**`npm run lint` passes**, **`npm test` passes (798 tests in 46 files)**.

The draw order is genuinely fixed and replay-safe (pool built from `SITES`
in declared order, `Array.prototype.filter` preserves order, `drawIndex` and
`drawTableAmount` each advance the seed exactly once, and the 22-step count
is asserted against 22 chained `mulberry32` calls). The advanced seed stored
on the state means the deal and the game's first draws never read the same
values. Both rules tables match the code exactly (drain average 14, pressure
average 12.79 by hand-check), the cap of 40 is two-thirds of `NODE_CAPACITY`,
and §8.1's claims about capacity left (46 average, 20 worst, ~22/~10 turns
against the 2.1 and 4.6 drain averages) all hold. No source or test file
still asserts or describes the old fixed opening as the ruleset's opening;
`Board.test.tsx` keeps that board only as an explicitly labelled arbitrary
fixture. The Step 4 and Step 5 test rewrites preserve what the suite
previously proved (the deleted "not a site" case is still covered by
`gameState.test.ts` and by the deal block's exact key-set assertion). No
Critical findings; the balance decision (D11) and the absence of a shared
fixture helper (D9) are treated as settled and are not raised.
