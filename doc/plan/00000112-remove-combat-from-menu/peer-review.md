# Peer Review — Story 00000112, Remove Combat from the start screen

## Summary

The branch removes the Combat option group from the start screen and the
matching state from `useAppScreen`, so `handlePlay` always dispatches
`combatEnabled: false`. The rules layer, session and Quick Guide are left
alone, and `README.md` drops the combat choice from its start-screen list and
rewords its opening paragraph. The change matches both the story and the
plan. No ruleset file changed, which is correct: the story says which choices
the app offers is an app decision, not a rule. The plan includes a README
step (Step 2). `npm run typecheck` passed. `npm run lint` passed with no
findings. `npm test` passed: 90 files, 1993 tests. `npm run format:check`
also passed.
