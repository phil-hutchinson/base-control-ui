# Peer Review — Story 00000109, Planet resources: a stable variant, and new defaults

## Summary

The branch splits the planet choice in two: a classic **planet bonus** (off / 2 points / 3 points) for continuous, planet and dedicated, and a steal-only **planet resources** setting (off / stable / race). Race is the old advanced setting, renamed. Stable leaves out the survivor's redraw. The app defaults become steal, required and race. The ruleset goes to 0.42, with `RULES_VERSION` and a single changelog entry moving together. The code vocabulary changes from "advanced" to "activity", and the Quick Guide and `README.md` follow. The rule logic matches steal.md §10 as amended:

- The stable claim skips exactly one draw.
- The new bonus's kind excludes the kind the survivor kept.
- Availability is checked after the claim's own effect.
- `startingGameState` rejects any value a playstyle does not offer, and resolves an omitted default against the chosen playstyle.

The tests cover the stable claim with a one-step-fewer seed comparison against race, a fight under both values, full-game invariant sweeps under both, and seeded replay.

The plan includes a README verification step (Step 6), and it was done. The owner decided to keep "activity" as the internal code name while the player-facing name is "planet resources", so that choice is not a finding here. The Quick Guide diagram now draws in the required-matching look because it follows the app defaults; the owner accepted this, so it is not a finding either. All findings are Minor. Most of them are about comment wording left by the late mechanical rename from "planet activity" to "planet resources".

- `npm run typecheck`: clean.
- `npm run lint`: clean.
- `npm test`: 90 files, 1969 tests, all passing.
- `npm run format:check`: clean.
