# Peer Review — Story 00000067, Three- and four-ship fleets

## Summary

The branch adds three- and four-a-side fleets: `rules.md` goes to 0.28 with two
new §4 layout tables, four new starting squares (C1, C15, M1, M15) and a
corrected §3.1 diagram; `src/rules/fleet.ts` widens `FleetSize` to `3 | 4 | 5 |
6` and adds the two layouts; the error message in `gameState.ts` is rebuilt from
`FLEET_SIZES`; and tests grow at the fleet, game-state, full-game, session,
start-screen and app levels. The start screen and its CSS needed no change (D4
held), and the README is brought into line.

`npm run typecheck`, `npm run lint` and `npm test` (1047 passed, 59 files) are
all green at HEAD.

The central correctness question checks out. I verified mechanically that
`fleet.ts`'s four layouts match `rules.md` §4's tables square-for-square and
colour-for-colour, that all four are exact half-turn rotations (column `i → 14 −
i`, row `r → 16 − r`) of the opposing colour, that the §3.1 diagram now carries
exactly the twelve planets `planets.ts` computes (including the restored `I12`)
and exactly eighteen `S` marks, and that §4 matches `story.md`'s stated layouts.
The findings below are all around the edges of that: one step-boundary defect in
the plan, and wording/comment issues.
