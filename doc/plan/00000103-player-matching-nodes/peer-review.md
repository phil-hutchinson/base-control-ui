# Peer Review — Player-matching nodes

## Summary

The branch adds a steal-only pre-play choice, Player-matching nodes (OFF / DOUBLE / REQUIRED). It includes the 0.40 ruleset bump (`steal.md` §9, pointers from `rules.md` §8.4 and §10, one changelog entry, `RULES_VERSION` to match), and a leaf option module. It also adds `GameState.playerMatching`, validated against the playstyle, and a single `turnCollection` function that the payout, the pips and the live region all read. The UI work is the red/green matched-node colours, the lengthened (and shrunk) DOUBLE pip row, the REQUIRED crossed pips, the reordered start screen, a Quick Guide section with a diagram, a README update and two accessibility-ledger entries. The implementation follows the story and plan closely. Step 6's owner-approved change from the "×" glyph to a background cross in the side's colour is recorded in that step's Notes. The plan includes a README step (Step 9).

- `npm test`: 81 files and 1714 tests, all passing.
- `npm run format:check`: also clean.
