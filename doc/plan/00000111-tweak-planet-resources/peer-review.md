# Peer Review — Story 00000111, Planet resources: new weights, and an in-place Node scramble

## Summary

The branch moves the ruleset to 0.43. It makes Fuel's kind weight
needs-based (`fuelWeight`, 10 plus missing power capped at 30, measured
from the ships at each kind draw) and raises Additional nodes and Node
scramble to 15. It replaces the old scramble with `shuffleProspectiveSignals`,
an in-place shuffle of signals done in two phases and fully drawn. It
removes the per-square `extra` flag in favour of a count
(`nodeCarriesExtra`), simplifies `nodeAnchor`, and drops `removedSquares`
from the claim outcome and effect. The Quick Guide and the announcement
wording change to match.

The code matches `steal.md` §10 as rewritten. The version, `RULES_VERSION`
and changelog moved together in their own commit (9e81a04). The tests
cover the formula, when the weight is measured, the shuffle's invariants,
the number of seed steps and the red/green guarantee. The plan includes a
README check (Step 4), and README needed no change. No comment breaks the
convention against design history or story citations. The findings are all
Minor: gaps in the documents, one gap in the tests, and comment wrapping.

- `npm run typecheck`: clean.
- `npm run lint`: clean.
- `npm test`: 90 files, 1994 tests, all passed.
- `npm run format:check`: clean.
