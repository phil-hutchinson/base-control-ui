# Peer Review — 00000018 One action per turn

## Summary

The branch takes the ruleset from 0.8 to 0.9 (a turn is one action), moves
`ACTIONS_PER_PLY` from 2 to 1, follows the count through code comments and the
nine test files that failed at the new count, restyles the turn indicator to
`GREEN TO PLAY` / `RED TO PLAY` in the side's colour, and updates the README's
Status paragraph. All five plan steps are recorded as committed, including the
owner play-test and a README step, so the plan's README check is present.

`npm run typecheck` passes, `npm run lint` passes, and `npm test` passes (40
files, 648 tests) — as does `npm run format:check`. The rules edit, changelog
entry and `RULES_VERSION` bump moved together in Step 1, and §8.3/§8.4/§9's
turn-counted clocks were correctly left alone. The findings below are about
residue left behind by the count change: rule citations in code that point at
a sentence 0.9 deleted, tests that still narrate a two-action turn, and one
restructured test that no longer proves what its name claims. Nothing in the
diff contradicts `rules.md` in observable play.
