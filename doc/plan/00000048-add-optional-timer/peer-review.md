# Peer Review — 00000048 An optional clock

## Summary

The branch adds an optional per-game clock: rules 0.18 → 0.19 (new §10, edited
§2/§5/§8.6/§9, changelog entry, `RULES_VERSION` bump), re-ordered and re-valued
Ships/Rounds options, a third start-screen option group, an `outOfTime` flag on
`GameState` with two new session intents, an out-of-time pass reusing
`applyPassGuard`'s machinery, a pure reading formatter, a ticking
`useGameClock` hook, and a `ClockRegion` replacing the `RESERVED` placeholder.
All fifteen plan steps are recorded as committed, including both manual gates,
and the diff matches the plan closely; the two recorded deviations (step 11's
`state.sideToMove`-derived running mark, step 2's extra literal sweep) are
documented in their Notes.

`npm run typecheck` passes. `npm run lint` passes with no findings.
`npm test` passes: 53 files, 894 tests. (`npm run format:check`, which the plan
also requires, passes.) The findings below therefore all come from reading the
diff against the story, the plan and `doc/ruleset/rules.md`.
