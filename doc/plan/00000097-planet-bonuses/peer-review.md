# Peer Review — Story 00000097, Planet bonuses

## Summary

The branch adds the eighth pre-play choice (`Planet bonus`: OFF / 2 POINTS /
3 POINTS), a seeded deal of three planets a side, a once-per-player-per-planet
payment made at every landing (move road and both of a fight's placements), a
new `planet-bonus-claimed` effect with its live-region sentence, a panel above
the clocks showing both sides' planets and their badges, and the matching
rules, README and Quick Guide copy. `rules.md` moved 0.37 → 0.38 with a
matching `RULES_VERSION` and a single changelog entry, and the OFF path
consumes no extra seed steps, so `seededReplay.test.ts` keeps its recorded
expectations untouched.

Checks run from the repository root: `npm run typecheck` — **clean**;
`npm run lint` — **clean**; `npm test` — **78 files, 1522 tests, all
passing**. §3.4 of the ruleset and the code agree on every clause I could
check (deal, distinctness, independence, once per player per planet, landing
via move and via both fight placements, immediate payment outside the
end-of-turn order), and nothing in the code implements a rule the document
does not state. No Critical or Major findings; the items below are all
documentation drift, comment convention or small design tidiness, and none of
them blocks the story.
