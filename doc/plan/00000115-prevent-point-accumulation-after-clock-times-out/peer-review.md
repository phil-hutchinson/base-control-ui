# Peer Review — Story 00000115: No energy after the clock runs out

## Summary

The branch bumps the ruleset to 0.45. A player whose clock has run out now gains no energy from any source. The rule is added to `rules.md` §10, and §3.4, §8.4, §8.6 and steal.md §10 now point to it. `RULES_VERSION` and the changelog were updated in the same, separate commit. In code, `turnCollection` now treats "out of time" as a second reason to withhold the collection, alongside REQUIRED. The end-of-turn payout and the score pips follow from that. The classic planet bonus does nothing for an out-of-time side, and a planet-effects claim resolves in full but pays 0 points. The README and the clock option tip were also updated.

Checks: `npm run typecheck` passes. `npm run lint` passes with no findings. `npm test` passes (92 files, 2069 tests).

The rule logic matches the ruleset. One logic gap remains in the score cell's hidden sentence under DOUBLE (#1). The other findings are about documentation drift and test coverage. The plan includes a README check (Step 3).
