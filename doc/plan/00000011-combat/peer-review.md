# Peer Review — 00000011 Combat

## Summary

The branch implements §7 combat in full: a new `src/rules/combat.ts` (adjacency,
the refusal union, the fight arithmetic and §7.1's receptacle), `applyAttack`
sharing a newly extracted end-of-action tail in `ply.ts`, a `returnPositionIndex`
on `GameState` drifting in §8.7's step 6, a §5-level `actions.ts` that widens the
pass guard from moves to actions, the attack gesture and its wording in the
session and `announcements.ts`, and the board's target ring, corner-triangle
return cues and reshaped `hasMoved`/`ShipCondition` split. It opens with the
rules edit to 0.6 (Appendix A closed, §7.1's availability argument extended) in
its own commit with the changelog entry and the `RULES_VERSION` bump together,
and closes with the fixture removal and the README update.

`npm run typecheck` passes, `npm run lint` passes with no findings, and
`npm test` passes — 466 tests in 30 files, all green. The rule logic was checked
against `doc/ruleset/rules.md` §3.1, §4.1, §5, §6, §7, §7.1, §8.5 and §8.7 and
no contradiction with the document was found; the ring direction, the drift
arithmetic, the `winner − (loser + 1)` cost, the mutual-return ordering and the
§8.5 blanket refusal of attacks all match what the document states. All twenty
plan steps are recorded committed, with deviations noted in their Notes lines.
The findings below are coverage, contract and convention points, not rule
defects.
