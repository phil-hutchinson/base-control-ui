# Peer Review — Story 00000069, Retire the action

## Summary

The branch retires the action across the whole stack: `rules.md` goes to 0.32
with the word gone and no "standard game" named, both appendices move to a new
`doc/ruleset/tech-notes.md`, and the code loses `ACTIONS_PER_PLY`,
`actionsRemaining`, `actedThisPly`, the `ship-already-acted` refusal, the
top-edge already-acted marking and the "N actions left" announcement branch.
The surviving pinned-ship condition, `src/rules/actions.ts` and
`PassReason`/`EndOfActionEffect` are renamed to say what they mean
(`canMoveOrAttack.ts`, `cannot-move-or-attack`, `EndOfPlyEffect` per O1). All
eight plan steps are implemented in the order and shape the plan set out, and
the rules document, `RULES_VERSION`, the changelog entry and the code moved
together in one version bump.

Checks from the repository root: `npm run typecheck` clean, `npm run lint`
clean, `npm test` green (64 files, 1183 tests — down from the 1216 baseline, as
the plan predicted for the deleted unreachable cases). `npm run format:check`
reports only the two pre-existing warnings (`src/board/planetArt.ts` and this
folder's `story.md`), which are not this story's to fix. No check produced a
finding.

Nothing in the diff contradicts `doc/ruleset/rules.md`, and nothing implements a
rule the document does not state, so there are no Critical findings. The plan
included a README step (Step 7, which both reworded the two stale passages and
re-read the rest of the README against the story), so no finding is owed there.
`CLAUDE.md`'s **Move** entry still reads "the movement action specifically" —
put to the owner rather than raised below, and left as it stands by their
decision, for a later vocabulary pass.
