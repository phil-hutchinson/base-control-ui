# Peer Review — Story 00000118, Improve pip rendering

## Summary

The HUD score pips are now small inline SVGs instead of CSS-styled `<span>`s. Each one has a 10-unit viewBox, a circle of radius 4.5, and for a crossed pip two diagonals that run from rim to rim. Strokes are a non-scaling 1px, and the lit glow is a `drop-shadow` filter where it used to be a `box-shadow`. The class names and the `--pip-fill` custom property are kept, so the existing selectors and colour logic are unchanged. There is no ruleset change, and the plan includes a README check step, which is recorded as done. `npm run typecheck` passes, `npm run lint` passes with no findings, and `npm test` passes (92 files, 2055 tests).

Checks against the story, the plan and the ruleset found no problems:

- **Story.** Every stated requirement is met: smooth outlines, a round glow on lit pips, and crosses drawn evenly across the circle. Pip meaning, order, colours and values are unchanged.
- **Plan.** The plan and the story agree, and nothing was built that neither one covers.
- **Rules.** No rule logic was touched.

The findings below are small: one undocumented numeric change, a slight size drift, and some tidy-ups.
